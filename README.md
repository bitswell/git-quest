# git-quest

Learn git through 4 arcade-style browser games.

## Games

| Game | Genre | What You'll Learn |
|------|-------|-------------------|
| **GitVania** | Metroidvania | Git commands as abilities — branch, merge, checkout, rebase — to explore a commit-graph world |
| **Git Detective** | Investigation | Git forensics — log, blame, bisect, diff — to solve cases |
| **Rebase Racer** | Side-scroll runner | Quick command recall under pressure |
| **Merge Conflict** | Falling-block puzzle | Conflict resolution — pick sides, combine changes, keep your codebase clean |

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Tech

TypeScript, Vite, HTML5 Canvas. No heavy frameworks — just games.
